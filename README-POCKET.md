# Kot Defense — Pocket Edition (Android)

Та же игра, но код умеет запускаться и на Windows, и на телефоне, а APK
собирается в облаке GitHub Actions — Android SDK/NDK на твой компьютер
качать не нужно.

## Что изменено в коде

| Файл | Что сделано |
|---|---|
| `android_support.py` **(новый)** | Платформенный слой: определяет Android, находит папку игры, создаёт окно под размер экрана телефона, масштабирует кадр 1400×800 с полями, переводит координаты касаний в игровые, глушит курсор и Discord RPC. |
| `config.py` | Экран теперь создаётся через `Display` (на телефоне — фуллскрин + letterbox), добавлена функция `present()`, звук инициализируется безопасно, датапаки лежат в абсолютном пути. |
| `managers.py` | `pypresence` импортируется необязательно и RPC выключен на Android; `PathManager` и сохранения используют абсолютные пути (`ANDROID_PRIVATE`); курсор не трогается, если ОС его не умеет; нажатие обновляет позицию «мыши» (палец без движения); битый/неподдерживаемый звук не роняет игру. |
| `main.py` | Жёсткие пути с `\` заменены на `res(...)`, вместо `pygame.display.flip()` — `present()`, иконка и датапак обёрнуты в try/except. |
| `classes.py` | Пути к шрифтам без обратных слэшей. |
| `buildozer.spec` **(новый)** | Конфиг сборки APK: `pygame==2.5.2`, landscape, arm64-v8a, API 34. |
| `.github/workflows/build-apk.yml` **(новый)** | Сборка APK на серверах GitHub. |
| `_smoke_test.py` **(новый, в APK не попадает)** | Быстрый прогон игры без окна: `python _smoke_test.py`. |

## Запуск на ПК

```bat
pip install pygame-ce
python main.py
```

Проверка без окна (полезно после правок):

```bat
python _smoke_test.py
```

## Как получить APK (без установки Android SDK)

1. Создай на GitHub пустой репозиторий (можно приватный).
2. В папке проекта:

   ```bat
   git init
   git add .
   git commit -m "Pocket edition"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/kot-defense.git
   git push -u origin main
   ```

3. На GitHub: вкладка **Actions** → слева **Build Android APK** → **Run workflow**.
4. Первая сборка идёт 40–90 минут (в облаке компилируются SDL2, Python и pygame).
   Повторные — быстрее за счёт кэша.
5. Внизу страницы запуска: **Artifacts** → `kot-defense-apk.zip` (~50 МБ).
6. Распакуй, скинь APK на телефон, установи (разреши «Установка из неизвестных источников»).

Трафик: загрузить ~20 МБ исходников, скачать ~50 МБ APK.

## Что работает и что пока нет

Работает: запуск, меню, слоты сохранений, магазин по тапу, волны, эволюции,
звук (если кодеки сборки это позволяют), сохранения между запусками.

Пока нет:
- **наведения курсора** — на телефоне нет hover, поэтому подсветка кнопок при
  наведении и часть hover-анимаций не появятся (логика клика работает);
- **клавиатуры** — консоль отладки (`,`/`` ` ``) и горячие клавиши недоступны;
- **мультитача** — одновременно один палец;
- **производительности** — кадр 1400×800 масштабируется каждый кадр; на слабых
  телефонах возможны просадки, лечится уменьшением логического разрешения.

## Если сборка упала

1. Открой упавший запуск в Actions, скачай артефакт `build-log`.
2. Ищи в конце лога первую строку `Command failed` / `error:` — она и есть причина.
3. Частые случаи:
   - `No matching distribution` / сеть — повтори запуск;
   - ошибка в рецепте `pygame` — попробуй в `buildozer.spec` заменить
     `pygame==2.5.2` на `pygame` (возьмёт версию рецепта по умолчанию);
   - `Java version` — проверь, что в workflow ставится `openjdk-17-jdk-headless`.

## Логи с телефона (если APK ставится, но падает)

Нужен `adb` (platform-tools, ~10 МБ):

```bat
adb logcat -s python SDL:V
```
